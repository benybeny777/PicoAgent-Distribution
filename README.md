# PicoAgent

**キャラクターと会話しながら、調べものやPC作業を手伝ってもらえるデスクトップAIアプリです。**

文字や音声で話しかけると、質問に答えたり、ファイルを扱ったり、予定を知らせたりします。キャラクターは独自2.5D・Live2D・MMDに対応。ローカルAIを使えば、会話をPC内で処理できます。

## できること

以下は開発版1.2.19の機能概要です（2026-10-05確認）。公開インストーラーは以前の版のため、使える機能が異なります。

- **キャラクターと会話** — 文字・音声で話しかけ、読み上げや口パク、表情を楽しめます。
- **調べもの・作業の手伝い** — Web検索、ファイル操作、文書処理、予定・リマインダーなどを会話から実行できます。
- **写真や画面について質問** — 写真やスクリーンショットを添付し、「何が写っている？」「エラー文を読んで」と頼めます。
- **AIの切り替え** — PC内のローカルAI、Ollama、クラウドAI、導入済みのClaude Code／Codex CLIを接続先に選べます。
- **複数AIで分担** — 複数のAIに同じ質問をしたり、仕事を分けて結果をまとめたりできます。
- **外部サービスとの連携** — Gmail、Google Workspace、GitHub、Slackなど、設定したサービスを利用できます。
- **自分の手順を追加** — Markdownで手順を書き、AIに使わせることができます。

### キャラクターと表示

| 形式 | 対応内容 |
|---|---|
| 独自2D / 2.5D | 付属キャラクターのまばたき、口パク、視線、表情、待機動作 |
| Live2D | 利用者が用意したCubism 4／5モデルの表示、モーション、まばたき、口パク |
| MMD | 利用者が用意したPMX 2.0モデルの登録、待機姿勢、ポーズ、表情、まばたき、口パク |

MMDの剛体・制約による物理演算は未対応です。モデルを追加する際は、配布元の利用条件を確認してください。

表示はミニ・ペット・配信の3形式から選び、キャラや会話表示の位置・大きさを調整して保存できます。

## インストールと使い方

1. [Releases](https://github.com/benybeny777/PicoAgent-Distribution/releases)から対象OSのインストーラーを取得します。
2. 起動後の案内で、AIと必要な追加機能を選びます。ローカルAIの初回利用にはモデルのダウンロードが必要です。
3. 会話画面から文字を入力するか、音声入力で話しかけます。キャラ・音声・AI・操作権限は設定画面で変更できます。

初回のモデル取得後は、ローカルAIとの会話をオフラインで利用できます。Web検索・外部サービス・クラウドAIには通信が必要です。外部APIの利用料は各サービスの条件に従います。

## データと操作権限

設定や会話履歴はPC内へ保存します。ローカルAIとの会話はPC内で処理し、クラウドAIや外部サービスは選択・設定した場合に使います。

ファイル操作は許可した範囲に限定し、削除相当の操作はOSのゴミ箱へ移します。PC操作・ブラウザ操作・ローカルAPI・MCP連携は既定で無効です。AIの回答や画像内の文字・数値は誤る場合があるため、必要に応じて確認してください。

## 技術概要

Rust / Tauri 2で開発しています。AIへの接続、ツール実行、音声、キャラクター描画を分け、接続するモデルやキャラクター形式を差し替えられる構成です。

| 領域 | 主な技術 |
|---|---|
| デスクトップアプリ | Rust、Tauri 2、Tokio、HTML / CSS / JavaScript、WebView2（Windows） |
| ローカルAI | llama.cpp、GGUF |
| 写真・画面の読み取り | Gemma 4 E2B |
| 音声入力・読み上げ | whisper.cpp、AivisSpeech |
| キャラクター表示 | PIXI.js、独自メッシュリグ、Cubism Core、pixi-live2d-display、MMD描画ランタイム |
| キャラクター制作 | Python、PyTorch、Grounding DINO、SAM、ComfyUI、Qwen-Image-Edit |
| 外部連携 | 各社AI API、JSON Schema、MCP、OpenAI互換HTTP API |
| 検証・配布 | Cargo、cargo xtask、Playwright、NSIS |

AIが必要なツールを選び、実行結果を受け取って次の処理を判断するループを実装しています。75種の組み込みツールを共通のインターフェースで登録し、モデルごとのAPI形式の違いは接続部分で吸収します。複数AIの分担には同時実行数の制限を設けています。

推論エンジンの起動・終了、モデル取得とハッシュ検証、状態更新のロック、破損データの退避、WindowsのDPAPIによる秘密値保護もアプリ側で管理します。キャラクター制作と表示を分け、表示中は画像生成モデルを動かしません。

本体の検証は`cargo xtask verify`へまとめ、書式、静的解析、テスト、JavaScript構文、画面の契約、仕様と実装の対応を確認します。GUI、マイク、音声品質、GPU、インストーラーの動作は実機で別に確認します。ゲーム画面を見て1操作する機能は初期実装で、安定したゲームプレイは未確認です。
